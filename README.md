# BiliLiveRec

B站直播（原画）录制器

## 注意

- 无需登录（也不能登录），故不能录制弹幕流。

- 仅支持fmp4流录制，部分分区和直播模式无fmp4流，会报错而不能录制。（暂未写ts流的fallback）

- 录制时务必保证网络通畅，最好开启ipv6支持，网络不畅时录制可能频繁 录制延后 或 彻底断开

## 使用方法

### GUI

- 点击 房间-添加

- 在输入框中可输入房间ID或完整链接，可自动识别。**不支持b23.tv短链。**

- 完成后，会显示一个黑色NONE标志。右键，点击 启动录制 如变为绿色IDLE标志或者红色REC标志，即为正常工作。

- 如果添加了多个房间，也可使用 房间-启动录制 一键启动全部。（顺序启动，如果某两个房间启动延迟较长，只要没有报错，等待即可）

- 录制时，日志会有提示，并且状态统计也应该有更新，如没有这些并且显示红色报错，请检查错误信息。

- 停止录制有两种方法：正常停止（PAUSE）和结束进程（EXIT）。如果正常停止，那么工作进程仍会在后台运行，但不再录制。结束进程时是彻底退出该进程。

### CLI(Worker)

**非必要情况，不建议直接启动worker**

- 使用如下参数启动即可：

```bat
BiliLiveRec.Worker.exe {ID} "{Path}"
```
其中，ID为房间的**真实ID**（类似1、233、5050这种短ID不是真实ID，必须通过API获取真实ID），Path是录制的输出路径。

## 录像输出

在设置的输出文件夹内，输出文件会有两部分：录制文件夹和日志log文件。

日志文件中会连续记录录制的状态，追加写入不会覆盖。

录制文件夹会以 房间ID\启动录制时间 命名，文件夹中：

`Cover.jpg`为当前直播的封面

`Info.json`为录制开始时获取的房间元数据信息（原始数据）

`Statistics.log`为录制统计数据，记录运行时长、房间基本信息和视频分片。该文件仅在录制正常退出时创建

`Video.{X}.mp4`为视频主体，从0开始排序。如果同一文件夹有多个mp4，说明主播在直播过程中切换分辨率、码率或与其他主播连麦

`Video.{X}.map`为视频m3u8片段的专有记录，其中记录了B站原始m3u8数据，以及mp4视频中各个分片的起始和结束位置

`Crc32FailedList.txt`为录制过程中可能出现的CRC32失败且不能恢复的分片列表。该文件仅在出现一次及以上CRC32失败时才会创建
